# E-Commerce & Product Operations Dashboard

A Streamlit dashboard starter using reproducible synthetic data.

## Setup
1. Create and activate a virtual environment (recommended).
2. Install dependencies: `pip install -r requirements.txt`
3. Generate datasets: `python generate_data.py`
4. Run the app: `streamlit run app.py`

## Data files
- `data/orders.csv`: 10,000 order-line records covering 2025.
- `data/customers.csv`: 2,500 synthetic customer records.
- `data/products.csv`: 100 synthetic products.
- `data/inventory.csv`: stock snapshot for 100 products.

All records are fictional and intended for dashboard development and practice.
